# Church photo albums

Each folder in here is one album on the website's Photos page.

## Add a new album
1. In GitHub, open this `photos` folder and click **Add file → Upload files**.
2. Before dragging the pictures in, type the album folder name in the file path box, then a `/`, for example:
   `2026-10-04 Ladies Early Morning Service/`
3. Drag in the pictures and click **Commit changes**.

Netlify updates the website automatically in about a minute.

## Tips
- Start the folder name with the date (`YYYY-MM-DD`) so albums show newest first.
- Name one picture `cover.jpg` to choose the album cover. Otherwise the first picture is used.
- Phone pictures are fine. The website shrinks them automatically for fast loading.
- To remove a photo or album, delete it in GitHub.
